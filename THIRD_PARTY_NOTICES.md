# Third-party notices

The macOS launcher downloads a pinned CPython runtime from
[python-build-standalone](https://github.com/astral-sh/python-build-standalone).
That project packages CPython and its dependencies under their respective open
source licenses. The runtime is downloaded directly by the tester and is not
stored in this repository.

The macOS release bundle contains
[pyserial 3.5](https://github.com/pyserial/pyserial), distributed under the
3-clause BSD license. Its wheel retains the package metadata and license text.
